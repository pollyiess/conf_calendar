# 📅 ConfCalendar

Календарь научных конференций — веб-приложение для агрегации, поиска, создания и отслеживания научных мероприятий и их дедлайнов.

## 🚀 Стек технологий

* **Backend:** Ruby 3.x, Rails 8.1.2
* **База данных:** SQLite 3
* **Аутентификация:** Devise
* **Тестирование:** RSpec (`factory_bot_rails`, `shoulda-matchers`)
* **Контейнеризация:** Dev Containers (Docker)

---

## ✨ Основные возможности

* **Каталог конференций:** просмотр предстоящих мероприятий с фильтрацией по индексации (Scopus, eLIBRARY).
* **Создание и управление:** возможность публикации новых конференций с указанием сроков подачи и параметров индексации.
* **Контроль дедлайнов:** автоматическая проверка статуса и сроков подачи заявок.
* **Закладки (Избранное):** сохранение интересующих конференций в личный кабинет.
* **Рекомендательная система:** персональный подбор конференций для пользователей на основе их интересов, сохраненных закладок и тематики исследований.

## 🛠 Запуск проекта

### Вариант 1. Через Dev Container (Docker + VS Code)

1. Откройте проект в **VS Code**.
2. В появившемся окне нажмите **Reopen in Container** (или `Ctrl+Shift+P` ➔ `Dev Containers: Reopen in Container`).
3. Среда и зависимости настроятся автоматически.

---

### Вариант 2. Локальный запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/pollyiess/conf_calendar
   cd conf_calendar

2. **Установите гемы:**
   ```bash
   bundle install

3. **Подготовьте базу данных:**
   ```bash
   bin/rails db:prepare

4. **Запустите сервер:**
    ```bash
    bin/rails server
    ```
Откройте браузер по адресу: http://localhost:5000
